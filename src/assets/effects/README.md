# Podklady zábavných efektů

Podklady jsou importované ze zdrojů, aby je Vite zabalil také do TV receiveru
a vytvořil správné cesty pro nasazení do podadresáře. PNG zachovávají původní alfa kanál.

Aktuální Radkovina používá skleněná čísla naplněná pivem, vytvořená vestavěným
nástrojem OpenAI imagegen podle schválené varianty PIVNÍ SKLO:

- `radkovina-number-7.png` — 1254 × 1254, číslo 7.
- `radkovina-number-19.png` — 1254 × 1254, číslo 19.
- `radkovina-number-3.png` — 1254 × 1254, číslo 3.

Přesná zadání i režim generování jsou v `NUMBER-PROMPTS.json`.
Plnění odspodu a drobné pohybující se bublinky vykresluje aplikace.
Nahrávku hlášky efekt nemá; běžný hlasatel oznámí součet 29.
