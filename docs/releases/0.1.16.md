# Šipky 0.1.16 pro Linux x86_64

Oprava zbytečné aktualizace zvuků ve vydání 0.1.15.

- Aplikace znovu používá původní **zvuky 1.0.1 z vydání 0.1.10**. Již nainstalované kompatibilní zvuky se znovu nestahují. Balíček má 26 843 588 B (26,8 MB).
- Odstraněny dvě nepoužívané nahrávky „Radkovina!“ a jejich generování. Pivní animace zůstává a hlasatel dál oznámí součet 29.
- Aplikace používá také původní **hlasatel 1.0.0 z vydání 0.1.8**. Odstraněná změna jeho skriptu sloužila pouze k nepoužívaným nahrávkám. Již nainstalovaný kompatibilní hlasatel se znovu nestahuje. Hlasy Eliška/Martin i model zůstávají stejné.
- Shooter zůstává označený **PŘIPRAVUJEME** a není dostupný pro hraní.

V tomto vydání vzniká pouze nový DEB aplikace **0.1.16** a aktualizační manifest. Pokud už jsou nainstalované doplňky z předchozích vydání, mění se pouze aplikace. I zvuky 1.0.2 a hlasatel 1.0.1 z vydání 0.1.15 mohou zůstat — jsou kompatibilní a není potřeba je odinstalovávat ani stahovat starší verze.

Při první instalaci nebo při chybějících doplňcích použijte původní balíčky z odkazů níže. Verze 0.1.15 kvůli odstraněným nepoužívaným souborům zbytečně vyžadovala nové verze obou doplňků; 0.1.16 tento požadavek opravuje.
