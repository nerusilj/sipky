# Šipky 0.1.17 pro Linux x86_64

- Přehlednější příprava her: karty vedle sebe na Domů, kompaktní přepínání X01 / Cricket / Shooter nad přípravou a položka **Hra**, která otevře poslední skutečně spuštěný režim s uloženými parametry.
- Kompaktní výběr hráčů bez číslování. Seznam zachovává pořadí přidání; volba **Náhodné pořadí** losuje až při spuštění zápasu. Příprava je optimalizovaná i pro běžnou sestavu čtyř hráčů.
- Jednotná velikost ovládání, oranžové **Začít hru** s bílým textem, sjednocená typografie a nižší horní lišta s lépe čitelnou značkou Šipky.
- **Shooter lze zkušebně hrát se zapnutým DEV.** Bez DEV zůstává označený PŘIPRAVUJEME a start je blokovaný.
- Žluté doporučení přípravy zavření v X01 se zobrazí až po ztrátě možnosti zeleného dohozu během aktuálního kola. U vysokých nebo nezavíratelných počátečních zbytků se předčasně nezobrazuje; opravy hodů a Zpět podmínku přepočítají.
- Zdroj receiveru pro Chromecast obsahuje upravené rozložení, škálování podle skutečného viewportu a odlehčené efekty. Tyto změny se na TV projeví po samostatném nasazení receiveru.

Vzniká nový DEB aplikace **0.1.17**. Aplikace nadále používá původní **zvuky 1.0.1 z vydání 0.1.10** a **hlasatel 1.0.0 z vydání 0.1.8**. Již nainstalované kompatibilní doplňky se znovu nestahují; také novější kompatibilní doplňky z 0.1.15 mohou zůstat nainstalované. Při první instalaci nebo chybějících doplňcích použijte odkazy níže.
